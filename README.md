# Eliu & Renelyn Wedding Website

A free static wedding website designed for GitHub Pages.

## Publish
1. Create a **public** GitHub repository named `eliu-renelyn-wedding`.
2. Upload `index.html` and the `assets` folder (including its four PNG files) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Visit `https://YOUR-USERNAME.github.io/eliu-renelyn-wedding/` once deployment finishes.

## Customize
Edit `index.html` on GitHub and commit changes. The site will redeploy automatically.

## Notes
- RSVP uses an SMS link rather than collecting guests' personal information.
- The Google Maps button opens a search for the venue; verify the correct pin before sharing.
- Public GitHub Pages content and the invitation images can be viewed by anyone with the link.
